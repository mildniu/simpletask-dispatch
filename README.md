# SimpleTask Dispatch

一个轻量的内部派单系统，用于创建任务、指派负责人、提交阶段进展、确认完成或退回重办。

## 功能

- 账号密码登录，支持系统管理员和普通角色。
- 任务创建、接单、提交、确认、退回、删除和状态变更。
- 管理员 Web 管理页，可管理用户和查看全部任务。
- 移动端底部常驻导航，适配手机和平板。
- 图片附件支持缩略图和在线预览。
- SQLite 本地数据存储，无需额外数据库服务。

## 启动

```bash
npm install
npm start
```

默认访问：

```text
http://127.0.0.1:3000/
```

首次进入时会初始化系统管理员账号。

## 常用命令

```bash
npm run check
npm run smoke
npm run test:click
```

## 数据与隐私

运行数据、上传附件、日志、花名册和本地截图不会提交到仓库。公开部署或分享前，请确认不要提交真实员工信息、账号密码、接口密钥或业务附件。
